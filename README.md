# Web MDX プレイヤー

X68000 の音楽データ形式 **MDX**（MXDRV 形式）を、ブラウザだけで再生するプレイヤーです。
FM 音源コアには本物の **ymfm**（YM2151 / OPM）を WebAssembly 化した libymfm.wasm を使用しています。

**曲データは同梱していません。** お手持ちの `.mdx` / `.pdx` ファイルを読み込んで再生してください。

## 使い方

`index.html` をブラウザで開くだけで動きます（GitHub Pages でもそのまま公開できます）。

- **ファイル読み込み**: 「ファイルを選ぶ」から `.mdx`（PCM を使う曲は `.pdx` も一緒に）を選ぶか、枠へドラッグ＆ドロップ
- **LZX圧縮ファイル**: Mamiya LZX で圧縮された `.mdx` / `.pdx` もそのまま読み込めます（読み込み時に自動で展開します）
- **動作確認**: 内蔵の合成テスト曲（ドレミファソラシド）で音が出るか確認できます
- **フォルダ＆ランダム再生**: MDX ファイルの入ったフォルダを選ぶと、その中（サブフォルダ含む）の曲からランダム再生できます（参照される PDX があれば自動で読み込みます）

## 主な表示機能

- チャンネル毎のステータス表示（鍵盤ストリップ、レベルメーター、音色番号、PANPOT ゲージ）— X68000 の MMDSP を意識したレイアウト
- チャンネル毎のミュート／ソロ
- スペクトラムアナライザ（96 バンド）
- FM 音色パラメータ詳細表示（@番号クリック）
- チャンネル解析（ピッチ／音量トレース、チューナー式デチューン表示、VU 式音量メーター、ソフトウェア LFO の設定表示）
- 連続ランダム再生（フォルダ方式）

## 既知の限界

- 一部の曲ではスペクトル重心が参照実装とずれる場合があります（ピッチ・音量モデル・レガート・フェードアウト等の既知の差は 2026-11-21 までに修正済みですが、原因を特定できていないケースが残っています）
